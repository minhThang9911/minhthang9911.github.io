App Introduction

De&EnCrypt is a lightweight Android utility for developers, students, security learners, and users who need fast text conversion or hash verification on a mobile device.

The app is built for practical workflows: type or paste text, select a transform, run the operation, and copy the result. It supports common encodings, hashes, classic text transforms, Vigenere, and configurable Java Cryptography Architecture cipher options.

Local-first processing

Core text conversions, hashes, and cipher operations are processed on the device. The core app does not upload entered text, keys, IV values, or selected file contents to a developer server.

Built for developer use

The interface uses clear input and output panels, monospace text, copy/paste/clear/swap actions, system light and dark theme support, and file picker support for hash verification.

Google Play Store Description

Short description

Encode, decode, encrypt, decrypt, and hash text quickly.

Long description

De&EnCrypt is a lightweight utility for developers, students, security learners, and anyone who needs quick text conversion, hashing, encryption, or decryption on Android.

The app is built as a practical tool: type or paste text, choose a transform, run the action, and copy the result. It is useful for debugging encoded payloads, checking hashes, converting text formats, experimenting with classic ciphers, or testing Java Cryptography Architecture cipher modes.

Key features

  • Base32 encode and decode
  • Base64 encode and decode
  • Hex encode and decode
  • Binary encode and decode
  • Octal encode and decode
  • ASCII decimal conversion
  • HTML entity conversion
  • UTF-16 style escape conversion
  • Morse code conversion
  • Roman numeral conversion
  • Vigenere cipher support
  • SHA-256 and MD5 text hashing
  • File hash verification for SHA-256 and MD5
  • Cipher support for algorithms such as AES, ARCFOUR, Blowfish, DES, DESede, and RC4
  • Configurable cipher mode, padding, key, IV, and input/output format
  • Fast copy, paste, clear, and swap actions

Designed for developer workflows

  • Clean input and output panels
  • Monospace text for easier reading
  • System light/dark theme support
  • Output remains easy to review while controls stay near the bottom
  • File picker support for verifying file hashes
  • No account required

Privacy-focused core processing

Most text operations are performed directly on your device. Text, keys, IV values, and selected file contents are not uploaded to a developer server by the core app. The app uses ads, so advertising partners may process advertising-related data as described in the privacy policy.

Common use cases

  • Decode Base64 API payloads
  • Convert strings to Hex, Binary, Octal, or ASCII codes
  • Generate SHA-256 or MD5 hashes
  • Verify a downloaded file against a known hash
  • Test AES/DES/Blowfish cipher settings
  • Experiment with Vigenere, Morse, Roman numerals, and HTML entities
  • Copy converted text into another tool or app

Important notes

This app is a general utility and learning tool. Some cipher mode and padding combinations depend on Android's available crypto providers and may not be supported on every device. If an operation fails, the app shows an error message in the output panel.

De&EnCrypt does not replace a full password manager, key management system, or professional security audit tool. Always handle sensitive keys and data carefully.

1. Overview

De&EnCrypt is a text encoding, decoding, encryption, decryption, and hashing utility. The app is designed to process the text or files that you choose inside the app.

This Privacy Policy explains what data the app processes, what Android permissions the app and its integrated third-party SDKs use, how data is handled, and how you can request deletion of data.

2. Data processed by the app

The core De&EnCrypt app processes the following data only when you provide it:

  • Text that you type or paste into the input field.
  • Keys, IV values, alphabets, and other parameters that you type for encryption or decryption.
  • Files that you manually select through the Android file picker for hash verification.
  • Text copied to or pasted from the clipboard when you use the Copy or Paste actions.

The core app uses this data to perform the requested local operation, such as Base64 encoding, Hex conversion, SHA-256 or MD5 hashing, Vigenere processing, or cipher encryption/decryption.

The core app does not require account registration and does not ask for your name, email address, phone number, contacts, photos, precise location, or other personal profile information.

3. Local processing of text, keys, and files

Text conversions, encryption/decryption operations, and text hashing are performed on the device.

For file hash verification, the app opens only the file that you explicitly select through the Android system file picker. The app reads the file to calculate a hash value and compare it with the hash text entered by you. The app does not request broad storage access and does not scan your device files.

The core app does not upload your entered text, encryption keys, IV values, or selected file contents to the developer's server. The developer does not operate a backend server for collecting this app content.
